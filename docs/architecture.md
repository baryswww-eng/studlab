# STUD LAB — архитектура

## Схема

```text
Браузер ──► Next.js (SSR, :3000) ──► FastAPI (:8000) ──► PostgreSQL
   │              │ API_INTERNAL_URL        │ ──► Google Gemini API (только с сервера)
   └──────────────┴─► NEXT_PUBLIC_API_URL ──┘
   └──► youtube-nocookie.com (встроенный плеер)
```

- **Frontend** отвечает только за интерфейс. Бизнес-правила и проверка прав — на backend.
- **Backend**: `api` (HTTP, валидация) → `services` (логика) → `repositories` (SQL) → `models`.
- Все endpoint с префиксом `/api/v1`; ошибки — `{"error": {"code", "message"}}`.

## Решения

| Вопрос | Решение | Почему |
|---|---|---|
| Язык | Только русский; next-intl с одной локалью, URL без префикса | решение заказчика; язык можно добавить без переписывания |
| Контент курсов | Таблицы `course_translations`, `lesson_translations` с `locale` | многоязычность заложена в схему |
| Авторизация | Email + пароль, Argon2id, JWT в HttpOnly-cookie `SameSite=Lax` | без внешних сервисов; токен недоступен JavaScript (XSS) |
| Firebase | Пробовали, отказались | Google требует 2FA на аккаунте владельца; своя авторизация проще |
| Доступ к урокам | Публичный, без записи | решение заказчика; прогресс — только для вошедших |
| «Мои курсы» | Запись в `enrollments` создаётся при первом пройденном уроке | нет лишнего шага «Записаться» |
| AI | Google Gemini через backend, модели `*-latest` с запасными | бесплатная квота; ключ не уходит в браузер |
| Лимиты | В памяти процесса (гости, вход) и по БД (AI для вошедших) | для нескольких экземпляров API перенести в Redis |
| БД для разработки | PostgreSQL из pip-пакета `pgserver` в `.local/` | Docker не установлен, админ-права не нужны |
| Запуск кода (будущее) | Отдельная песочница с лимитами CPU/RAM/сети | код учеников никогда не выполняется в API |
